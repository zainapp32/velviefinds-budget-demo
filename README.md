# Velvie Finds Budget — Free Demo

A limited **free demo** of the Velvie Finds Budget ADHD-friendly budget planner app.

**Try it:** open the demo (GitHub Pages link for this repo) and explore — Safe-to-Spend,
paycheck budgeting, bill tracker, budgets, savings goals, debt payoff, envelopes, calendar and themes.

**Demo limit:** the demo saves data **10 times**. After that, saving pauses and you'll be
invited to get the full version. Everything you already saved stays visible.

**Full version (Etsy):** unlimited saves, one single HTML file you own forever, works 100%
offline, no subscription, no account, no bank connection — your data never leaves your device.
